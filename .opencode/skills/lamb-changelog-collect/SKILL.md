# Lamb Changelog Collector

Этот навык предназначен для безопасного и контролируемого обновления секции `[Unreleased]` в файле `CHANGELOG.md`.

## Процесс работы

1. **Анализ истории:** При вызове навыка анализируется история git-коммитов с момента последнего релиза (тега).
2. **Классификация:** Коммиты распределяются по категориям: `Features`, `Bug Fixes`, `Refactoring` и т.д.
3. **Группировка:** Однотипные правки объединяются в общие пункты.
4. **Форматирование:** Формируется структурированный блок в формате:
   `- type: \`module\` - description`
5. **Предложение (Фаза 1):** Пользователю выводится готовый вариант обновлённой секции `[Unreleased]`.
6. **Подтверждение:** Ожидается явное подтверждение пользователя перед записью в файл.
7. **Применение (Фаза 2):** После подтверждения секция `[Unreleased]` в `CHANGELOG.md` обновляется.

## Пример использования

> Обнови секцию `[Unreleased]` в `CHANGELOG.md`: собери новые изменения из лога коммитов...
